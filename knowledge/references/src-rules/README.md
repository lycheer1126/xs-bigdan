## 收录模板（新平台照此结构写）

1. 评分模型（货币/积分 × 应用系数矩阵）
2. 定级锚点（严重→低危各自的判断要点，按 Agent 判定视角提炼）
3. 无影响/不收清单（Agent 判定防坑）
4. 计数与时效规则（同源多洞、同类型上限、nday/时效）
5. 受理范围与域名归属（Scoping 红线）
6. 对 Agent 的操作映射（Scoping/报告/提交策略）
