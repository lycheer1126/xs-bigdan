## 2. 评分模型（积分 = 漏洞级别 × 应用权重；1 积分 = 5 元）

| 等级 | 基础积分 | 核心产品(权重7-10) | 重点产品(2-6) | 一般产品(1) |
|---|---|---|---|---|
| 严重 | 150-200 | 1050-2000 | 300-1200 | 150-200 |
| 高危 | 60-80 | 420-800 | 120-480 | 60-80 |
| 中危 | 10-16 | 70-160 | 20-96 | 10-16 |
| 低危 | 1-10 | 7-100 | 2-60 | 1-10 |

核心产品（权重 7-10）：**有钱花**、度小满理财、度小满金融、度小满商家助手。
重点产品（2-6）：度小满保险、区块链。一般产品（1）：关联业务/API 站点/服务器。
定级锚点与 AntSRC 高度同构（同一行业模板）：严重=核心权限/核心敏感数据/核心逻辑（账密校验、
核心接口验证、支付逻辑）/直接命令执行 SQLi；高危=普通权限/重要数据/本地执行/需交互存储XSS（核心应用）；
低危=特殊条件利用/路径 phpinfo/本地DoS/恶意注册套现/越权低危三条件。

## 3. 特殊规则（DXMSRC 独有——影响提交策略）

- **短信轰炸（横向类）暂不接收**——与其他平台不同，别测。
- **同源漏洞打包提交 = 1.1 倍奖励**（鼓励打包，与其他平台"同源 75%"相反）。
- **越界零分 + 报案**：上传 webshell、反弹 shell、内网扫描探测、恶意拖取数据、下载源码——
  0 分处理且有权报案配合刑侦。⚠️ 我们的内网探测纪律在此平台要**最严**：只证明可达即停。
- 未脱敏报告外发/未修复外发 → 减少或取消奖励，甚至注销账号。
- 内部已知问题（业务方反馈短期无法修复）不再重新收取计分。

## 4. 威胁情报赛道（独立评分——DXMSRC 特色）

漏洞之外单独收**威胁情报**：积分 = 情报等级 × 完整度系数（非常完整 7-10 / 一般 2-6 / 不完整 1）。
完整度五维：威胁来源(×2) / 攻击目标(×2) / 攻击方法(×4) / 威胁损失(×1) / 威胁时间(×1)。
情报严重=核心服务器入侵线索/核心DB拖取线索/洗钱大规模盗号/新型支付逻辑漏洞线索；
情报高危=核心代码仓库泄露/大规模蠕虫/可溯源入侵情报。
→ 打到入侵/黑产线索时按此结构整理证据再提交，完整度直接换钱。

## 5. 对 Agent 的操作映射

- Scoping：24 域名清单核对（§1）；"一般产品"权重 1 = 收益极低，优先核心产品面。
- 打包提交策略：同源漏洞攒齐一次打包（1.1 倍加成）。
- 内网纪律最严档：discover 即停，严禁任何主动内网交互（此平台明文 0 分+报案）。
- 威胁情报赛道：实战中发现黑产/入侵线索时按 §4 五维结构整理单独立项。
