# AntSRC（蚂蚁集团安全响应中心）平台规则

> 来源：AntSRC 官方评分标准（2026-09 版本）。**目标属于蚂蚁系资产时本文件优先于通用评级标准**，
> 报告定级/评分/受理判断全部以本文件为准；通用框架见 `references/rating-standard.md`。
> 提交入口：security.alipay.com · 邮箱：antsrc@service.alipay.com · 保密义务：泄露细节收回奖励。

---

## 1. 评分模型（金币 = 基础金币 × 应用系数）

| 等级 | 基础金币 | 核心应用(×10) | 一般应用(×4) | 边缘业务(×1) |
|---|---|---|---|---|
| 严重 | 110-130 | 1100-1300 | 440-520 | 110-130 |
| 高危 | 40-60 | 400-600 | 160-240 | 40-60 |
| 中危 | 5-15 | 50-150 | 20-60 | 5-15 |
| 低危 | 1-4 | 10-40 | 4-16 | 1-4 |

核心应用 = 支付宝、芝麻信用、蚂蚁财富、网商银行、蚂蚁小贷、蚂蚁金融云、余额宝、招财宝、蚂蚁花呗。

## 2. 定级锚点（Agent 报告定级对照）

- **严重**：核心服务器权限 / webshell / 核心敏感数据泄露 / 核心业务逻辑漏洞（账密校验、支付逻辑、
  核心数据接口）/ 可直接命令执行的 SQLi / 核心DB（资金/身份/交易）低难度 SQLi 出大量用户数据。
- **高危**：普通服务器权限 / 重要敏感数据泄露（用户信息、订单、数据文件）/ 本地代码执行 /
  **无需交互的存储 XSS** / 文件遍历 / 参数处理不当的远程拒绝服务 / 非核心DB低难度 SQLi 出大量业务数据。
- **中危**：需交互才危害用户（反射XSS / CRLF / 敏感操作 CSRF）/ 普通信息泄露（登录后手机号、姓名、
  交易号）/ 远程拒绝服务 / 非核心业务逻辑漏洞 / 营销活动作弊、业务规则绕过 / **存储 XSS 不能影响全量
  用户或有 HttpOnly 防护的独立域名应用**。
- **低危**：特定条件下才能利用（特定浏览器反射XSS / 存储XSS）/ 服务器物理路径、phpinfo、本地日志 /
  本地拒绝服务 / 利用成本极高（特殊中间人、连续交互）/ 恶意注册、薅羊毛套现类 / **越权但门槛高、
  无敏感信息、用户无感知、非重要功能** / 开放重定向等低风险业务逻辑。

## 3. 无影响清单（Agent 判定防坑——以下禁止标漏洞，连 INFO 都慎写）

- Self-XSS（无法影响他人）/ 恶作剧 CSRF（对用户无实际影响）/ 无法影响他人的本地拒绝服务
- **非敏感信息泄露：内网 IP、内部域名**（⚠️ SSRF 报告注意：仅证明可达内网但无数据/凭证 = 低价值，
  必须打出版本目录/凭证/数据才够中危以上）
- 无任何证据的猜测（"付款不扣款""账户被盗"类）
- 产品体验/设计问题、非安全原因的服务不可访问

## 4. 评分规则要点（直接影响提交策略）

- **同源多洞计一**：同一漏洞源产生的多个漏洞 = 一个。同域名同类型漏洞**最多确认 3 个**（按提交时间）
  → Agent 发现同型洞时**集中证据测深 3 个**即可，别刷数量。
- **同一报告多个漏洞只按最高级别计** → 高价值发现单独成报告更划算（提交策略，Agent 在报告层标注分组建议）。
- **nday 规则**：第三方组件 nday——已公开 ≤半年且平台已知晓 → 驳回；平台未知晓或公开 >半年仍未修复 →
  按实际演示效果定级。**必须附 CVE 编号 + 链接 + 可利用证明（信息泄露/控制 PC 的 PoC）**。
  对应知识库：`references/1day/`（PENDING 状态条目用前必须差分确认）。
- **时效性**：3 年以外的安全事件原则上不受理（以公开发布时间为准）。
- 未修复前被公开的漏洞不计分；网上已公开的不计分 → **发现要尽快提交并保密**。

## 5. 受理范围与域名归属（Scoping 红线）

- **不受理**：开源产品的非安全风险、开放平台沙箱环境 `openapi.alipaydev.com`（正式环境 alipay 才收）、
  无明显信息定位为蚂蚁资产的、3 年以上旧事件。
- **蚂蚁域名但归 ASRC（阿里SRC）管，别报 AntSRC**：`yunxiao.cloud.alipay.com`、`aone.cloud.alipay.com`、
  `mall.alipay.com`、`ynuf.alipay.com`、`b.antfinancial-corp.com`、`*.koubei.com`。
- **阿里集团域名但归 AntSRC 收**：`*.aliloan.com`、`*.aliloan.cn`、`baoxian.taobao.com`、`licai.taobao.com`。
- 蚂蚁/阿里员工不得参与；恶意报告封号。

## 6. 对 Agent 的操作映射

- Scoping：白名单外发现关联域名时，先查本文件 §5 归属再决定测不测/报哪家。
- 报告：证据须"10 分钟内可复现"+ 完整请求响应；保密，不向第三方透露细节。
- SSRF/信息泄露类：对照 §3 无影响清单自查（内网 IP 泄露本身不算），把影响写到数据/凭证层面。
- 同类型多发：挑最有代表性的 3 个作为提交主体，其余在报告注明"另有同类 N 处可补充"。
