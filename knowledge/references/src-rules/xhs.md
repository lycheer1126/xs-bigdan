# 小红书安全响应中心（XHSSRC）平台规则 V3.0

> 来源：官方《安全风险报告处理规则 V3.0》（2026-08-19）。**目标命中小红书资产时本文件优先**。
> 提交入口：security.xiaohongshu.com · 1 安全币 = 1 元（税后）· 邮箱：sec@xiaohongshu.com。
> **四类报告分轨**：技术漏洞 / 威胁情报 / 风控异常线索 / 隐私合规——风控异常线索（账号风控+反爬）是 XHS 独有赛道。

## 1. 奖励模型（与其他平台最大的结构差异）

技术漏洞奖励 = 危害等级 × **等级内子级 W**（同等级内位置 1-3 级，按危害强度/影响范围/利用条件/实际利用 0-8 分）
× **业务价值 B**（B1 有限 0-1 / B2 一般 2-4 / B3 重要 5-7 / B4 关键 8-10，按关键业务依赖+覆盖+数据权限+连续性评估）。

| 危害 | B1 | B2 | B3 | B4（关键业务） |
|---|---|---|---|---|
| 严重 3级 | 800-900 | 3600-4000 | 6200-7000 | **10700-12000** |
| 高危 3级 | 350-400 | 1930-2200 | 3170-3500 | 5000-5500 |
| 中危 2级 | — | 470-530 | 670-730 | 870-930 |

**应用等级**：核心（App/Web 主站功能点）→ 高危/严重可定；一般（ark 商家后台/聚光 ad/蒲公英/creator/
OA/SSO/CRM 内部系统）→ 高危可定；边缘 → 低危为主；**外采系统原则上酌情只收高危/严重**。

**高质量报告奖 +20%**：利用思路新颖、手法独特的报告——报告里写清楚"为什么这个思路别人没想到"。

## 2. 技术漏洞定级锚点

- **严重**：核心服务器权限（webshell/RCE）/ 核心任意账号接管 / 任意金额支付（可提现、>10 万）/ 
  用户严重敏感身份信息泄露（**≥100 万条且 ≥3 个敏感字段**）/ 远程系统级永久拒绝服务（CDN 投毒 ≥24h）。
- **高危**：敏感越权/未授权（绕过认证进管理后台、管理员弱口令、越权他人核心功能——**参数无法简单遍历
  （超长 id）会降级**）/ 核心业务信息泄露（≥3 敏感字段且 >1w 条）/ **可访问内网且有完整回显的无限制
  SSRF** / 预期外 1-2 折无限制获取核心资源 / 核心客户端永久 DoS。
- **中危**：需交互获取身份/操作账户（存储 XSS、敏感操作 CSRF、oauth 绑定劫持）/ **可访问内网但无完整
  回显或有限制的 SSRF** / 非核心单接口越权、非核心 SQLi、任意文件读（非敏感）/ 绕过限制获取部分高级
  服务 / **6 位以上验证码爆破最高中危** / **普通信息泄露最高中危**。
- **低危**：特定非流行浏览器 XSS / GitHub 非敏感源码、phpinfo、SVN / **无回显 bind 类 SSRF** / 频控缺陷
  （无风控的短信轰炸）/ 影响小的越权（收藏/购物车）/ 反射及 DOM XSS / 敏感 JSONP / DLL 劫持 /
  host 碰撞（无法进一步利用）/ 内部非公开文档泄露 / 任意 URL 跳转。

## 3. 忽略清单（Agent 判定防坑）

非小红书资产 / 无法利用或条件苛刻（含利用条件苛刻降级场景）/ Self-XSS / pdf-XSS / **内网 IP、域名泄露** /
静态目录遍历 / 无意义 API Key / 扫描器输出报告（基线策略类）/ 用户名枚举 / HTTP 明文 / 无意义 CORS 劫持 /
401 基础认证钓鱼 / HTML 注入 / 参数无法遍历的越权或未授权访问 / **Nday 已知不收** / **并发短信轰炸（后端
有风控）不收** / 邮件轰炸 / **内部已知或专项治理期间不收**（查《暂停收录列表》）/ 无依据猜测。

## 4. 合并与计数

- **同一漏洞源**（同 JS/同发布系统/同框架/泛域名/同接口多参数 XSS/同资源 ID 越权）→ 只收确认的第 1 个。
- **同系统同类型手段相似**：60 天内重复提交记**前 3 个**为有效（与其他平台的"前 3"一致）。
- **同一功能的越权增删改查合并成一个报告**。
- **利用顺序链**：按链路能达到的最大危害计分（弱口令进系统后发现越权 → 按越权危害计）。

## 5. 威胁情报与风控异常线索（XHS 独有双赛道）

- **威胁情报**：账号黑灰产 / 内容流量作弊 / 电商广告资金作弊 / 直播创作者生态 / 数据泄露 / 入侵攻击 /
  AI 新型作弊 七类收录。定级看业务影响 + 实际危害 + 规模化能力；完整度系数 L1 线索型 0.4 / L2 可验证
  0.7 / L3 完整 1.0（严重 L3 = 8500-10000 元）。数据泄露情报**仅提供 3-5 条脱敏样本** + 至少两项佐证。
- **风控异常线索**（账号风控 + 反爬两向）：批量注册养号/自动化操作/绕过频控与设备识别/稳定获取受保护
  数据的协议脚本。评级按业务影响/可规模化/绕过深度/资源成本/稳定性/现实利用六因素。
  **最小必要原则**：证明风险成立后立即停止；数据样本 ≤5 组脱敏；**账号盗用只用两个自行注册的测试账号
  交叉验证**——与我们"两账号差分金标准"完全同构。

## 6. 对 Agent 的操作映射

- **SSRF 官方靶标**（已同步进 hunt_ssrf §2a 表）：有回显 `http://10.11.23.35:5555/flag.html`；
  无回显 `http://10.11.23.35:5555/ssrf_forward?host=yourdnslog.domain`（host 直接填域名不带协议）。
  **分级直接决定**：完整回显=高危、有限制/无完整回显=中危、无回显 bind=低危 → store-and-read 把低危拉到高危。
- 报告末尾写一段"思路新颖点"——**高质量报告奖 +20%** 唾手可得。
- 内部已知/专项治理期间不收：打之前查《暂停收录列表》；连续疑似撞内部已知 → digest 标注并换面。
- 隐私合规独立赛道（隐私政策缺失/违规收集/超范围索权），与我们技术漏洞轨分开，别混报。
