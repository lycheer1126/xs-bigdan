# SRC 测试纪律（红线与习惯的单一权威）

> 2026-09 收敛：此前散落在 clown 主 SKILL、experience 各台账、system.md 报告三闸——
> 一个知识点分放多处且有出入。本文件是**纪律层唯一权威**；手法定位的纪律（如 CORS 技术细节）
> 留在对应漏洞文档，本文件管"怎么测的行为边界"。
> 新案例消化时的纪律性教训一律登记到本文件对应节，不再散写。

## 1. 会话纪律（用户供给登录态后）

- **严禁登出/注销/吊销令牌**：不调用 /logout /signout /revoke 类接口；不测"退出后会话仍有效"
  （会话固化是客户端漏洞且需要破坏会话）。**保持供给的会话全程有效**——会话一断，后续所有认证后测试全停。
- 消歧：「禁登出」管的是**用户供给的会话**；"注销→重新登录"类测试指用**自己的测试账号**重新走
  登录流程（如登录响应包 roleCode 篡改），两回事——前者禁、后者是正常测试路径。
- Cookie/Token 是**活凭据**：只存任务目录（gitignored 区），不写入任何会入 git 的文件。
- 凭据失效（接口开始统一返回登录跳转）：停止认证后测试，改走未授权面或 BLOCKED 求助，不尝试重新登录（无密码）。

## 2. 写操作纪律（写越权要测，但有顺序）

- **先加后清**：写越权测试顺序 = 先**添加**（看能否挂到别人名下/越权字段）→ 再**删除自己刚添加的那条**。
  不改/不删他人已存在的订单、地址、密码、角色。
- 只能动现成对象时：选**自己能改回去**的字段（昵称/备注类），打一次，改回，留前后对照证据。
- 改密/改绑/改角色：**可探**（去掉旧验证字段看是否放行），**放行即立刻改回**；改不回就停在回包证据。
- 永不做：扣款、清库存、真资损、批量写、删除他人数据。
- 把"只读红线"理解成"写越权不用测"是错的——写越权是高危主类，纪律管的是**恢复原状**，不是禁止测试。

## 3. 类型取舍纪律（省预算的硬规则）

- **CORS 永久不挖不报**（SRC 平台不收）：见 20-cors 决策树技术存档；登录/重置/改绑链路也不单独测。
- **低产类型**（clown 短表标注"几乎不交"，默认跳过；现场特征极强才顺手）：HPP、纯 CRLF 头注入、
  悬空标记、邮件头注入、CSV 公式注入、XSLT 注入、点击劫持——**这些不单独开测试流**，
  碰到特征时按其指针转打对应高价值类型（如 Host 毒重置走 28-host-injection）。
- 预算优先级：越权/IDOR > SSRF（低成本高价值，hunt_ssrf）> 认证绕过 > 注入类 > 低产类型。

## 4. 目标行为纪律

- **禁开工盘问**：默认已是授权 SRC 语境（BRIEF 白名单即授权证明），不盘问授权书/身份。
- **禁停工请示**：「要不要继续」「下一步您看」类问句不出现——预算内自主推进，卡点走 BLOCKED 协议。
- **登录页不是换资产的理由**：先找业务面（同 host 网关/跳转后 host），无会话时主业打未授权面；
  登录表单可见的弱口令/接管探测按 xs_auth 末位层打完即收，不在验证码上死磕（成本红线）。
- **作用域墙**（scope=root 默认）：可测 = BRIEF 的 L1 主目标 + L2 同根域被动引用扩展（发现须逐条记
  `evidence/_scope_expanded.json`，来源要可追溯；禁止猜测/爆破子域）；**L3 跨根域记录不测**（只写 digest 线索，
  由人工确认归属后加目标）。scope=strict 只测显式 host。跳转出域（SSO 等）记录不测。

## 5. 报告措辞纪律（与 system.md 报告三闸互引，以 system.md 为门、本文件为解释）

- 匿名闸/认钥闸/别重复交：详见 system.md「报告三闸」，此处不重复正文。
- 禁糊话：写"泄露 2 个手机号实值"不写"等敏感信息"；影响按最终伤害写全（能改能删能转账都写）。
- 未打过的门不写；没证明链的升级链不写（"可进一步接管"需写出路径与前置条件）。
