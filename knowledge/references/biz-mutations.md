# 业务参数扰动字典（biz-mutations）

> 来源：113 条实战动作级碎片蒸馏。用法：对每个业务参数依次套用所属族的扰动，
> **命中即停**，落证据。`[引擎]` 标记 = 已进 PairingEngine 语义组可自动消费；
> 未标记条目手工测试。合规：扰动 ≤3 次/参数，命中即停，不做持续轰炸。

---

## 族1：状态翻转族（决策值藏在参数里）

| 扰动 | 适用参数 | 期望信号 |
|---|---|---|
| `1→0` / `0→1` | status/isVip/isAdmin/enabled | 状态机跳步：审核态直通、会员态直开 `[引擎]` |
| `1→-1` | status/orderStatus | 负数绕过正数白名单判断 `[引擎]` |
| `false→true` | sms_code/verified/agreement/check | 前端验证后端不验 `[引擎]` |
| 审核态改写 | 返回包 status 字段 | 前端渲染"已审核"→多出可操作接口（发现面，非直接洞） |
| 未到期/过期标记 | 活动id + 时间参数 | 过期活动带 id 复活参与 |

## 族2：类型替换族（支付/身份/通道）

| 扰动 | 适用参数 | 期望信号 |
|---|---|---|
| `type=1→3` / `→40` | 支付/订单/权益类型 | 直接支付成功/开通会员 `[引擎]` |
| `userfrom/logintype` 替换 | 注册/登录来源参数 | 走免验证注册通道/账号枚举 |
| 低价 id 替换 | 商品/服务/医生/课程 id | 低价对象的价格买到高价对象 |
| 免费资源 id 进付费接口 | 课程/内容 id | 越权访问付费内容 |

## 族3：数量边界族（放大与精化）

| 扰动 | 适用参数 | 期望信号 |
|---|---|---|
| `pageSize=10000` / `size=-1` | 分页参数 | 数据量放大=批量拉取违规，**只取≤5条作证** `[引擎]` |
| 数值加 `.5` | id/数量/金额 | 绕过整数校验/越权探测（参数处理不一致信号）`[引擎]` |
| 超长同数字 | `1111111111`/`2222222222`/18位 | 暴露隐藏接口（返回差异）`[引擎]` |
| 时间戳 duration 拉大 | 查询时间段参数 | 查询范围放大 → 记录后只取≤5条证明 |
| 复写参数 | 商品id 多次出现 | 多次吃新人礼/重复权益 |

## 族4：置空删除族（校验依赖性探测）

| 扰动 | 适用参数 | 期望信号 |
|---|---|---|
| 参数置空 | 任意必填参数 | 服务端不验必填 `[引擎]` |
| 删 file/sign/token 参数 | 导出/下载/签名接口 | 差异越权：只剩 id 即可操作（id 越权删除）|
| 删 cookie 操作 | 已登录功能 | 探测鉴权载体（token vs session），token base64 可解=任意用户 |
| 逗号拼接多 id | 批量删除/选中操作 | 一个是自己的 + 一个是别人的 = 越权删除他人 |

## 族5：结构注入族（框架级参数）

| 扰动 | 适用参数 | 期望信号 |
|---|---|---|
| `sort=desc,0`（错）/`,1`（对） | 排序参数 | 排序注入（报错差异=注入点） |
| `filter={"LIKES_email":""}` | 列表过滤参数 | ORM filter 注入 → 全表枚举 |
| `id→ids` | 单数参数名 | 复数端点可能存在，列出所有用户 |
| `id` 加 `'` | 任意数值参数 | 报错差异 = SQLi 信号（转 `high-risk-probing.md`） |
| 自定义变量携带系统变量名 | 变量添加功能 | 覆盖/新增系统级全局变量 |

## 族6：身份替换族（水平越权，出洞率最高）

| 扰动 | 适用参数 | 期望信号 |
|---|---|---|
| id/userId/member_id 替换 | 任意对象操作 | 越权读/改/删（≤5条证明）`[引擎]` |
| 不可遍历 id → 抓上一包/下一包 | 详情页 | 相邻包里的 id 常可遍历 |
| 手机号/邮箱替换 | 退出/绑定/找回/通知 | 越权退出他人登录、绑定劫持、轰炸 |
| unionid/openid 替换 | 排行榜/展示页找值 | 跨体系身份接管 |
| 企业/组织 id 替换 | 待审核账号 + 泄露的企业id | 挂靠他人企业获得权限 |
| **返回包 id 回注请求包** | 响应中任何 id 类字段 | 手工必做（引擎值池来自 JS 静态分析，不覆盖实时响应） |
| 订单号枚举 | "不存在"vs"不属于当前用户" 差分 | 差分=可枚举，后续配合客服流程=他人订单操作 |

## 族7：编码/探针族（载体与协议）

| 扰动 | 适用场景 | 期望信号 |
|---|---|---|
| 邮箱后缀大小写/`&`拼接 | 验证码发送口 | 轰炸变体（≤3次验证即停） |
| `@` 触发解析 | 邮箱/IM/提及 | html 注入 |
| url 跳转参数塞伪协议 | 跳转 `xxx://javascript:...` | 跳转→XSS 链 |
| 上传 content-type 改 text/html | 图片/pdf 上传 | 存储型 XSS |
| base64 图片内嵌 payload | 图片内容 | 解析侧 XSS |
| 下载 filename=`C:\Windows\...\hosts` / `etc/passwd` | 文件下载参数 | 路径穿越/任意文件读取 |
| 文件名改为系统资源名 | 上传（logo 等固定路径） | 任意文件覆盖 |
| `Authorization: 1111` 伪造 | 无 token 接口 | 鉴权是否只看头存在性 |
| `X-Forwarded-For` 构造 | 回显 IP 的页面 | 头注入 XSS |
| iframe `data:text/html;base64` | 富文本/嵌入点 | sandbox 逃逸探测 |

---

## 与联动引擎的关系

`[引擎]` 条目的值已可被 PairingEngine 语义组消费（端点参数 × 扰动值自动配对）。
手工优先打未标记条目：**需要上下文判断的**（身份替换、返回包回注、结构注入）——
这些是"动作"而非"值"，引擎够不到，正是人工/agent 判断力的价值区。
