# xs-bigdan 测试账号池（复制为 credentials.txt 后填写；credentials.txt 已被 .gitignore 排除）
#
# 用途：注入目标 BRIEF 的「测试账号」节，让 agent 先登录再测认证后攻击面
#       （越权/IDOR/垂直越权/业务逻辑——多数 SRC 高价值洞在认证后）。
# 纪律：BRIEF 与 system.md 已写明——登录速率≤2次/秒、禁止爆破、命中即停、
#       失败 2 次即停写 BLOCKED。账号须是你自己注册的测试账号。
#
# 格式（每行一个账号；# 开头为注释）:
#   [scope|]user|pass[|备注]
#
# scope 匹配规则：
#   *  或 留空      → 注入所有目标
#   目标id 或 host  → 只注入该目标（host 支持主域后缀匹配，如 example.com 匹配 api.example.com）
#
# 示例：
# *|tester01|Passw0rd!|全局通用测试号
# www-01|tester02|Passw0rd!|主站专用
# card.qdedu.net|user03|Pass456|一卡通系统
